只用手的入门五步

不接机械臂，把手固定在桌上，从“让一个关节动一下”做到“让它自己把手心里的东西转起来”。走完这五步，就完整经历了一遍这个领域的标准流程。

为什么可以不要机械臂

机械臂负责“把手送到哪里”，手负责“手指怎么动”。如果东西是你直接放到它手里的，就不需要臂。

最常见的摆法是把手固定在支架上、手心朝上，像一只摊开等着接东西的手。很多有名的研究就是这么做的，比如文献库里的 OpenAI Dactyl、Hora、Rotating without Seeing、DeXtreme。

建议先用 Sharpa。它有两只，万一弄坏一只还有备份。前四步可以完全不管触觉，把它当普通的手用。等流程熟了，再把同样的东西在无极 2 上做一遍。

开始前要准备的

  • 一个固定支架。手不能直接放桌上，必须牢牢固定住。无极官方模型仓库的 step/adapter 目录里有安装转接件的图纸；Sharpa 的包装里自带桌面底座，不用另外做（见 Sharpa 开箱和接线）。
  • 一台 Ubuntu 电脑。两家的官方工具都以 Linux 为主。前四步普通电脑就行。
  • 第五步需要 NVIDIA 显卡。Sharpa 官方示例写明至少 32 GB 内存、Ubuntu 22.04。
  • 第一次上真手要慢。先把速度和力度限制调低，手边随时能断电。电源别插错：无极 2 是 12 V，Sharpa 是 18–28 V。

Sharpa 还没装好、没连上电脑？

开箱、装到底座、接线、连电脑、校准、关机，这些单独放在一页：Sharpa 开箱和接线 →。先把那一页做完，再回来做下面五步。

五个步骤

做完一步就勾上，进度会记在这个浏览器里。

  1. 01

    让手动起来

    做什么：装好厂商的软件，从电脑发指令让每个关节单独动一下，再读回它实际转到了多少度。

    为什么：这是在熟悉“电脑怎么和手说话”。后面所有事情都建立在这上面。

    做到这样算完成：你能写一小段 Python，让食指弯到 45° 再伸直，并打印出关节的实际角度。

    Sharpa先用官方桌面软件 Sharpa Pilot 校准和点动，再用 sharpa-wave-sdk 写代码控制（支持 Python 3.10–3.12）。
    无极 2wuji-sdk 写代码控制；wuji-studio 是带界面的桌面软件，可以先用它看数据。
  2. 02

    回放固定动作

    做什么：手动编几个姿势（握拳、比 OK、依次弯手指），让手按顺序、平滑地做出来。

    为什么：熟悉怎么编排一串动作，以及动得太快、太猛会发生什么。

    做到这样算完成：手能循环做一套你设计的动作，中间不卡顿、手指之间不互相撞。

    两只手都一样用第一步的软件就够了。把每个姿势记成一组关节角度，在两个姿势之间慢慢过渡，不要一步跳过去。
  3. 03

    用自己的手遥控它

    做什么：对着摄像头动你的手，机器人手跟着动。

    为什么：这一步会碰到“把人手姿势翻译成机器人手姿势”（论文里叫重定向，retargeting）。人手和机器人手的手指长短、关节数量不一样，不能直接照抄。这是后面录示范、用人类数据教机器人的基础。

    做到这样算完成：你捏拇指和食指，它也捏；你张开五指，它也张开。然后试着遥控它捏起一个放在手心里的小东西。

    Sharpasharpa-vision-retargeting-sdk：普通摄像头或 Meta Quest 头显都行，支持单手和双手。最新版 v1.0.3（2026-09-29），2026-08-27 才首次发布。注意：它默认控制左手，我们的是右手，运行时要加 --config-path supplements/sharpa_wave_right.yml。它没写是否支持 Wave SE，用的是普通版 Wave 的模型文件，能不能直接用要试了才知道。桌面软件里没有“摄像头遥控”这个选项。按手册，软件里能选的“控制来源”只有 4 个：软件自己（拖滑块、回放）、SDK（写代码控制）、GLOVE（数据手套，手册写“即将推出”）、IDLE（不动）。摄像头遥控是一个单独的 Python 程序，通过 SDK 发指令，所以要先在软件里把控制来源切到 SDK，再在终端运行遥控程序。同一时间只能有一个来源控制手。
    无极 2wuji-retargeting 负责姿势翻译；wuji-hand-teleop 是完整的遥控程序。
  4. 04

    在电脑里的虚拟世界跑一遍

    做什么：把手的模型加载进仿真软件，让虚拟的手做和第二步一样的动作，和真手并排对比。

    为什么：第五步要在虚拟世界里训练。先看清楚虚拟的手和真手差在哪（动得快慢、到位的准不准），心里有数。这个差别就是论文里说的 sim-to-real gap。

    做到这样算完成：同一组指令，虚拟手和真手做出来的动作大体一致，你能说出哪里不一样。

    Sharpasharpa-urdf-usd-xml 里有左手、右手、双手的模型文件，可以用免费的 MuJoCo 打开。
    无极 2wuji-hand-description 是模型文件；mujoco-sim 是加载并控制它的最小示例。
  5. 05

    第一个真正的任务：手心朝上转东西

    做什么：往手心放一个小圆柱或小方块，让手指自己把它原地转圈。没有人教它具体怎么动：在虚拟世界里让它反复试错（强化学习），练会之后搬到真手上。

    为什么：这是这个领域的“入门标准题”。做完它，你就完整走了一遍：虚拟世界里训练 → 搬到真手 → 发现不一样 → 调整。以后加机械臂只是多一个部件，流程是一样的。

    做到这样算完成：真手能把物体连续转几圈不掉。

    Sharpasharpa-rl-lab：官方的“手内旋转”完整示例，从训练、看效果到部署到真手一步步都有。默认用的物体是 3D 打印的圆柱。README 写的是半径 24 mm、高 60 mm，但仿真里实际训练的是半径 20 mm、高 32 mm（见任务 1 的 3D 打印）。
    无极 2wuji-isaaclab：无极 2 的“手内转方块”训练；wuji-mjlab：训练加部署到真手。

    这一步我们单独写了一页：任务 1：手里转圆柱（流程、奖励、我们的进度）。想了解背后的方法，读文献库里的 Hora。Sharpa 示例的训练步骤（先训练、再“蒸馏”）和它是同一个思路。
