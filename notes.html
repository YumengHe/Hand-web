2026-11-15问题 9

在官网下载页上找不到下载软件的地方，Sharpa 的软件到底在哪里下？

结论：不在官网上，在 GitHub 的发布页上。官网下载页只是一排跳到 GitHub 的链接，点进去看到的是说明文字，没有下载按钮。

软件改名了：手册里叫 Sharpa Pilot，现在叫 Sharpa Wave，是同一个软件。

下载：发布页。当前最新版 2.1.0（2026-11-06），文件是 sharpa-wave_2.1.0_amd64_linux.deb，约 310 MB，直接下载。

安装：cd ~/Downloads → sudo dpkg -i sharpa-wave_2.1.0_amd64_linux.deb → 提示缺东西就 sudo apt-get install -f。打开：应用菜单里找 Sharpa Wave，或终端运行 sharpa-wave。

注意：发布页上 2.1.0 有两个文件，另一个叫 sharpa-pilot_…。官方说明让装 sharpa-wave 那个。它自带配套的 SDK（装在 /opt/sharpa-wave-sdk/），官方要求不要自己另外装或改这份 SDK。

前提：必须切到 Linux（Ubuntu 22.04 最稳，24.04 也支持），这个软件没有 Windows 版。

进度（2026-11-15）：台式机已切到 Linux，Sharpa Wave 2.1.0 已安装（按上面的命令装的）。想确认是否真的装上：终端运行 dpkg -l | grep sharpa，能看到 sharpa-wave 一行、开头是 ii 就是装好了。Ubuntu 版本是 24.04：官方桌面软件支持，现在这几步都没问题；但后面“训练转东西”用的官方示例 sharpa-rl-lab 只在 22.04 上测试过，到那一步可能要多折腾，到时再处理。下一步：换网线 → 设地址 192.168.10.240 → ping 192.168.10.20 → 打开软件读黄灯的故障代码。

完整步骤：Sharpa 开箱和接线 → 让电脑连上它

2026-11-15问题 8

Sharpa 不用的时候怎么关机？

结论：没有开关按钮，拔电源就是关机。手里没有电池，电一断就彻底关了。

顺序：拿走手里的东西、停掉控制它的程序 → 关掉 Sharpa Pilot → 把电源适配器从墙上拔下来 → 灯全灭就是关好了 → 等 30 分钟再摸外壳。

不用拔的：手到接线盒、接线盒到电脑的线都可以留着。要拔的话先断电。

注意：手背的按钮不是关机键（按 2 次重启，按 3 次恢复出厂设置）。下次通电要重新校准。

来源说明：官方手册没有单独的“关机步骤”，这个顺序是根据手册的接线和安全说明整理的。

详细步骤：Sharpa 开箱和接线 → 不用的时候怎么关

2026-11-15问题 7

通电后亮黄灯，是什么意思？

结论：手背上的灯黄色常亮 = 有一条“警告”。不是出错（出错是红灯），是手发现了点小问题。具体是什么，要在 Sharpa Pilot 里看故障代码（FaultCode）。

手背灯的全部含义：青色一明一暗 = 待命，正常；白色常亮 = 工作中，正常；黄色常亮 = 警告；红色常亮 = 出错，停止操作；红色闪烁 = 严重故障，立刻停止。

先试这几样：确认没有东西碰着手指；外壳烫就断电放凉；拔掉电源等十几秒再插上，等 20 秒，期间别碰手。

还是黄灯：连上电脑读故障代码。常见警告：关节被掰过头、关节受力太大、温度偏高、触觉配置读写出错。

别看错灯：接线盒上的电源灯应该是绿色；网线插口旁边的小灯闪黄色是正常的。

结果：待补充（故障代码是什么、怎么解决的）。

2026-11-15问题 6

台式机只有一个网线接口，上网要用它，连手也要用它，怎么办？

结论：买一个“USB 转网口”的转接头，几十块钱。插在电脑的 USB 口上，电脑就多出一个网口。原来的网口继续上网，新的网口专门连手。Sharpa 官方的教程里也是这么用的。

买的时候认准：USB 3.0、千兆（1000 Mbps）。Ubuntu 一般插上就能认，不用装驱动。

今天就想试：先把需要的软件都下载好，然后把上网的网线拔下来，换成连手的网线。缺点是这期间电脑上不了网，如果你是远程连这台电脑的，拔了就连不上了。

如果电脑有无线网：也可以用 WiFi 上网，把网线口留给手。

设置地址时注意：192.168.10.240 这个地址只设在连手的那个网口上，上网的那个网口不要动。

接线和网络设置的完整步骤：Sharpa 开箱和接线 → Sharpa Wave SE

2026-11-15问题 5

Sharpa（标签 Wave SE-R-01）怎么装？电源怎么接？有没有 3D 打印件能把它立在桌上？

结论：箱子里自带桌面底座，不用 3D 打印。官方用户手册里有完整的开箱和接线步骤。

型号：SE 是 Sharpa 两档里规格较低的一档，R 是右手。

箱子里的 9 样东西：手本体、圆形法兰转接件、底座、L 形扳手、螺丝（M4 十颗、M6 八颗）、接线盒、电源适配器、网线、手腕线。

装：M6 螺丝把转接件固定到底座（对角线交替拧紧）→ 手放上去 → M4 螺丝固定 → 放在平稳的桌面。

实际用了多少螺丝（实测）：M6 用 4 颗（转接件到底座），M4 用 6 颗（手到转接件）。各剩 4 颗是正常的。

踩过的坑（实测）：顺序不能反。必须先装转接件和底座，再装手。先把手和转接件装在一起的话，手会挡住 M6 螺丝的位置，拧不上，只能拆掉重来。

两种螺丝怎么分：M 后面的数字是螺丝杆的粗细。M6 是粗的、短的（8 颗），用来固定底座；M4 是细的、长的（10 颗），用来固定手。入门五步页里有对比图。

接线：先确认没通电 → 手腕线一头插手腕背面、一头插接线盒（对准定位凸起直推，再拧紧螺母）→ 网线从接线盒连电脑 → 电源适配器先插接线盒的圆孔，最后插墙上插座。接线盒有两个电源口，只用圆孔那个。

那个不是充电器：手里没有电池，是电源适配器，用的时候一直插着。

通电后：等约 20 秒，别碰指尖。接线盒灯常亮绿色是供电正常；手背灯青色一明一暗是启动好了。

连电脑：Ubuntu 22.04，装 Sharpa Pilot。电脑网卡设成 192.168.10.240、掩码 255.255.255.0。右手出厂地址 192.168.10.20，用 ping 192.168.10.20 测试。

校准和试动：Sharpa Pilot 里 Calib → Start Calibration（约 95 秒，每次通电建议做一次，校准时别碰手）→ Sliders 面板拖滑块 → Replay 面板放预设动作。

安全：外壳会烫，断电后等 30 分钟再摸；手动的时候别把手指伸到关节缝里；指尖别碰尖锐物，受力别超过 50 N；有异响立刻断电；别和无极 2 的 12 V 电源混用（Sharpa 要 18–28 V）。

还没确认的：手册标题写的是 W01，没有单独提 SE，需要对照箱子核对包装清单是否一样。

完整步骤：Sharpa 开箱和接线 → Sharpa Wave SE：开箱、固定和接线 · 官方手册：在线版、PDF

2026-11-15问题 4

机器手一定要接到机械臂上用吗？有没有只用手就能做的简单任务？

结论：不一定。机械臂负责“把手送到哪里”，手负责“手指怎么动”。东西直接放到它手里，就不需要臂。把手固定在桌上、手心朝上，是很多有名研究的做法。

只用手的入门顺序：

  1. 让手动起来：从电脑发指令让每个关节单独动，再读回实际角度。
  2. 回放固定动作：编几个姿势让手按顺序做。
  3. 用自己的手遥控它：对着摄像头动手，机器人手跟着动。
  4. 在电脑里的虚拟世界跑一遍：虚拟手和真手做同样的动作，对比差别。
  5. 手心朝上转东西：在虚拟世界里让它反复试错练会，再搬到真手上。这是这个领域的入门标准题。

先用哪只：先用 Sharpa。有两只，坏了有备份，官方示例也更全。前四步可以不管触觉。

要准备的：固定支架（Sharpa 自带底座）、Ubuntu 电脑、第五步需要 NVIDIA 显卡和至少 32 GB 内存。

2026-11-15问题 3

无极 2 和 Sharpa 这两只手有什么区别？关节和自由度呢？

自由度：无极 2 是 20 个（每根手指 4 个）。Sharpa 是 22 个，多的 2 个在拇指（第二关节能左右摆）和小指（根部多一个让手掌能拢起来的关节）。四指的结构两只手完全一样。

活动范围：无极 2 每个关节能转的角度更大，手指能往手背反弯 60°。Sharpa 的范围和真人差不多。

触觉：Sharpa 每个指尖都有触觉，每根手指根部还有力矩传感器。无极 2 按官方文档，2.2 测试版没有触觉。

其他：无极 2 约 0.8 公斤、12 V 供电、每秒通信 1000 次；Sharpa 1.3 公斤、18–28 V 供电、每秒 500 次。

还没确认的：无极 2 的版本号（2.1 还是 2.2）；另一只 Sharpa 的标签。

2026-11-15问题 1

我们的手是 1 只无极 2 和 2 只 Sharpa。硬件不同会影响该读哪些文章吗？一个想法在无极 2 上验证了，能用到 Sharpa 上吗？

结论：思路能搬，练出来的成果不能直接搬，依赖特殊传感器的方法要看另一只手有没有。

打个比方：你学会了用筷子，换一双更长更滑的筷子。

  • “怎么夹”的道理还在。相当于论文里的方法和思路，换手之后照样能用。
  • 手感要重新练。相当于训练出来的那个具体“大脑程序”，它是针对某一只手练的，换手就得重新训练。
  • 有些事换了工具就做不了。如果一个方法靠的是指尖触觉，而另一只手没有这种传感器，就搬不过去。

所以读文章的优先级：

  1. 两只手都能用的先看：只靠“关节弯了多少度”这类基本信息就能干活的方法，比如在电脑里练好再搬到真手上的那批工作。
  2. 只有 Sharpa 能发挥的：利用触觉的工作。
  3. 用得上两只 Sharpa 的：双手配合的任务。
  4. 可以少看的：怎么自己造一只手，以及“用绳子拉手指”那类手的控制方法。我们两只手的电机都直接装在关节上，用不到。

一个机会：多数论文只在一种手上验证。我们同时有两种手，把同一个方法在两只手上都跑一遍，本身就是有价值的实验，尤其能回答“触觉到底带来多少提升”。
