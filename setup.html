Sharpa Wave SE：开箱、固定和接线

从拆箱到手指能动：装到底座上、接线、通电、连电脑、校准，以及不用的时候怎么关。全部做完，就可以开始“入门五步”了。

以下步骤整理自 Sharpa 官方用户手册的 Get Started 一章。我们这只的标签是 Wave SE-R-01：SE 是型号，R 是右手。（设备清单）

官方手册在线版 · PDF 版（174 页）
注意手册标题写的是 W01，没有单独提 SE。开箱和接线应该是一样的，但性能数字（指尖力、触觉）以 SE 自己的规格为准。

先分清两种螺丝

“M” 后面的数字是螺丝杆的粗细（直径，单位毫米），“×” 后面的数字是螺丝杆的长度。所以 M4 是细的，M6 是粗的。

最简单的分法：把两种螺丝并排放，杆更粗、更短的是 M6，杆更细、更长的是 M4。数量也能帮你确认：10 颗的是 M4，8 颗的是 M6。

拧不进去就停。螺丝拿错了会明显插不进或者晃荡，不要硬拧，换另一种试试。

第一部分：把手装到底座上

踩过的坑：顺序不能反。一定要先把转接件装到底座上，再把手装到转接件上。如果先把手和转接件装在一起，手会挡住 M6 螺丝的位置，M6 就拧不上了，只能拆掉重来。实测，2026-11-15
  1. 用 4 颗 M6 螺丝（粗的那种）把法兰转接件固定到底座上。对角线交替着拧紧，不要一颗拧死再拧下一颗。
  2. 把手放到转接件上。
  3. 用 6 颗 M4 螺丝（细的那种）把手固定住。
  4. 把装好的整体放在平整、稳当的桌面上。

实际用量（实测，2026-11-15）：M6 用 4 颗，M4 用 6 颗。箱子里给的是 M6 八颗、M4 十颗，所以装完会各剩 4 颗，是正常的，留着当备用。

第二部分：接线

  1. 先确认没通电。
  2. 接手腕线。一头插手（插座在手腕背面），一头插接线盒。插头上有个定位的凸起，对准插座的缺口，顺着直推进去，再把外圈的螺母拧到锁紧。对不准不要硬插。
  3. 接网线。一头插接线盒，一头插电脑。
  4. 接电源。先把电源适配器插到接线盒的圆孔上，最后再插墙上的插座。

接线盒上有两个电源口（一个圆孔、一个黄色的 XT30 口）。只用圆孔那个配原装适配器，两个不能同时接。

第三部分：通电检查

踩过的坑：通电前要先给手留出空间。第一次通电时手离墙太近，大拇指碰到了墙，手记下一条故障，之后校准连续失败了 3 次，还亮了红灯。四周至少空出一个手掌的距离，线别放在手指旁边。实测，2026-11-16 · 完整经过见“校准”部分的校准失败的完整经过
  1. 通电后等大约 20 秒。这期间不要碰指尖。
  2. 接线盒上的灯常亮绿色，说明供电正常。
  3. 手背上的灯变成青色、一明一暗像呼吸一样，说明手启动好了，电脑可以找到它了。

手背上的灯是什么意思

灯的样子意思怎么办
青色，一明一暗启动好了，待命中正常，不用管
白色常亮已启用，正在工作正常，不用管
黄色常亮有一条“警告”：手发现了点小问题，但还没到出错的程度在 Sharpa Pilot 里看故障代码（FaultCode），它会说具体是什么
红色常亮出错了停止操作，看故障代码
红色闪烁严重故障立刻停止操作，看故障代码

黄灯时先试这几样（不需要连电脑）：确认没有东西碰着或压着手指；摸一下外壳是不是很烫，烫就断电放凉；然后把电源从墙上拔掉，等十几秒再插上，等 20 秒，期间不要碰手。

还是黄灯：就必须连上电脑，在 Sharpa Pilot 里读故障代码。常见的警告有：关节被掰过了头、关节受力太大、温度偏高（70°C 以上）、触觉配置读写出错。

别看错灯：这张表说的是手背上那个灯。接线盒上的电源灯应该是绿色。网线插口旁边的小灯闪黄色或橙色是正常的，那只是表示网线在传数据。

第四部分：让电脑连上它

踩过的坑：电脑只有一个网口。手要占一个网口，上网也要占一个。解决办法是买一个“USB 转网口”的转接头（USB 3.0、千兆），原来的网口继续上网，新的专门连手。临时想试的话，可以先下载好软件，再把上网的网线拔下来换成连手的。如果电脑有 WiFi，就用 WiFi 上网，网线口专门连手，不用买转接头（我们的台式机就是这样）。实测，2026-11-15
踩过的坑：网线插好了，ping 还是不通。原因是电脑网口没有地址：Ubuntu 插上网线后，默认会向对方“要”一个地址（叫 DHCP，家里路由器就是干这个的）。手不会给电脑发地址，电脑等 45 秒要不到就放弃，然后一直重试。我们查的时候：网口显示已连接千兆，每秒也能收到约 1000 个从手那边来的数据包，就是没有 IP 地址。下面第 2 步的手动设地址不能省。实测，2026-11-16
  1. 电脑装 Ubuntu 22.04，安装官方桌面软件。这个软件以前叫 Sharpa Pilot，现在改名叫 Sharpa Wave，是同一个东西。官网下载页上没有直接的下载按钮，要到 GitHub 的发布页去下。当前最新版是 2.1.0（2026-11-06 发布），点这里直接下载，大约 310 MB。
    下载完在终端里运行：cd ~/Downloads，然后 sudo dpkg -i sharpa-wave_2.1.0_amd64_linux.deb。如果提示缺东西，再运行 sudo apt-get install -f。发布页上 2.1.0 有两个文件，另一个叫 sharpa-pilot_…，官方说明让装 sharpa-wave 这个。它自带配套的 SDK（装在 /opt/sharpa-wave-sdk/），官方要求不要自己另外装或改这份 SDK。装好后在应用菜单里找 Sharpa Wave，或者终端运行 sharpa-wave。
    ✅ 我们的台式机是 Ubuntu 24.04，已装好 2.1.0（2026-11-15）。24.04 用这个软件没问题；后面训练用的 sharpa-rl-lab 官方只在 22.04 上测试过，到那一步再处理。确认方法：dpkg -l | grep sharpa，看到 sharpa-wave 一行、开头是 ii 就对了。
  2. 把电脑插网线的那个网卡手动设置成：地址 192.168.10.240，子网掩码 255.255.255.0。
    在终端里运行这两条（每行一条；Wired connection 1 是 Ubuntu 给网线口起的默认名字，可以用 nmcli con show 查）： 
    nmcli con mod "Wired connection 1" ipv4.method manual ipv4.addresses 192.168.10.240/24 ipv4.never-default yes ipv6.method disabled
nmcli con up "Wired connection 1"
    ipv4.never-default yes 让这个网口只连手、不抢着上网，WiFi 照常用。设一次就永久生效。
  3. 右手的出厂地址是 192.168.10.20（左手是 192.168.10.10）。在终端运行 ping 192.168.10.20，有回应就是连上了。
    ✅ 我们的台式机已连通（2026-11-16）：3 个包全收到，延迟不到 1 毫秒。
  4. 打开 Sharpa Pilot，等手的卡片出现，点进去。

第五部分：校准，然后动一动

踩过的坑：校准报 [3] Soft limit validation failed。先别反复重试。把电源从墙上拔掉，等一会儿再插上，等手背变回青蓝色呼吸灯，挪到空旷的地方再校准。我们重启后一次就成功了。实测，2026-11-16 · 完整经过见“校准”部分的校准失败的完整经过
  1. 校准（让手知道“伸直”是哪个位置，官方建议每次通电都做一次）：进 Calib 面板，点 Start Calibration，等大约 95 秒。校准时手会自己动，人不要碰它，周围不要有东西挡着。
    成功后会显示 Calib From Params Success 和一行 dof_limit_diff：22 个关节和出厂位置差了多少度。官方没写多少算正常，我们这只成功时都在 1° 以内，可以作参考。✅ 我们这只已校准成功（2026-11-16），最大差 0.7°。
  2. 拖滑块：进 Sliders 面板，拖动滑块，对应的关节就会动。
  3. 放一段演示：进 Replay 面板，选一个预设动作，点 Play。
校准失败的完整经过、怎么读结果、去哪查故障码（实测，2026-11-16）

结论：第一次通电时大拇指碰到了墙，手里留下了一条故障记录。断电重启清掉以后，校准一次就成功了。手没有坏。

报错是什么意思：校准时手会让每个关节慢慢转到最远的位置（机械极限），把测到的位置和出厂时记下的位置对比。差太多就报 Soft limit validation failed（极限位置检查没通过）。

经过：

  • 第一次通电时手离墙太近，大拇指碰到了墙面。
  • 连上电脑后，手报了故障码 834（电机欠压保护），出在 4 号关节（大拇指指尖那节）。我们的推测是：手指顶着墙转不动，电机使劲推，那一瞬间电压被拉低，就记下了这条故障。手册里没有写这一条。
  • 之后一直没断电，带着这条故障校准了 3 次，每次都在 98% 失败。第 3 次之后手背开始闪红灯，又多了一个 1283（关节受力太大）。
  • 拔掉电源等了一会儿再插上，手背变回蓝灯，故障清掉了。挪到空旷的地方再校准，一次就成功了。

是不是电源的问题？不是。如果是电源不够，22 个电机会一起报欠压，还会出现整只手的供电故障（0x0203、0x0240）。实际上只有大拇指一个电机报了，所以和电源适配器无关。

校准成功后的输出怎么看：

Calib From Params Success
dof_limit_diff(in deg): [0.5 0.4 0.2 0.2 -0 -0.1 0.2 0 0 -0 0.2 0 -0.2 0.1 0.7 0 0 0 0.2 0.3 0 0]
[Backlash Commit] success: Motor calibration data saved successfully
  • dof_limit_diff：22 个关节这次测到的极限位置和出厂时差了多少度。全部不超过 0.7°（最大的是 14 号，无名指根部左右摆）。大拇指的 0–4 号都在 0.5° 以内，碰墙没有留下损伤。
  • Backlash Commit：齿轮之间有一点点空隙（回程间隙），换方向时会先空转一下。校准顺便把每个关节的空隙量测了出来，存进手里，以后控制时会自动补偿。

关节编号（0 到 21）：0–4 大拇指（根部弯曲、根部左右摆、中间弯曲、中间左右摆、指尖）；5–8 食指；9–12 中指；13–16 无名指（根部弯曲、根部左右摆、中间、指尖）；17–21 小指（手掌、根部弯曲、根部左右摆、中间、指尖）。来源：SDK 里的 sharpa_wave_example.py。

以后怎么避免：通电前先把手放到空旷的地方，四周至少空出一个手掌的距离，线别放在手指旁边；出了故障先断电重启，不要带着故障反复校准；闪红灯就立刻停下来。

想自己查故障码：软件的日志在 ~/.sharpa-wave/logs/日期/。故障码的含义在 /opt/sharpa-wave-sdk/include/SharpaWaveSDK.h 里，日志里的十进制数要先换成十六进制，比如 834 = 0x0342。

做到这里，下面“五个步骤”里的第一步就完成了一大半，剩下的是改用代码而不是界面去控制它。

第六部分：不用的时候怎么关

这只手没有开关按钮，关机就是拔电源。它里面没有电池，电一断就彻底关了。

  1. 先让手空下来。手里抓着东西就先拿走。有程序在控制它就先停掉程序，让手指停在自然张开的姿势。
  2. 关掉电脑上的 Sharpa Pilot。
  3. 把电源适配器从墙上的插座拔下来。接线盒的绿灯和手背的灯都灭了，就是关好了。
  4. 等 30 分钟再摸外壳。刚断电时可能还很烫。

其他的线（手到接线盒、接线盒到电脑）不用拔，留着下次直接插电就能用。如果要拔这些线，一定先断电再拔。断电后手指会变松，能被掰动，这是正常的。下次通电后要重新校准一次。

手背的按钮不是关机键：连按 2 次是重启，连按 3 次是恢复出厂设置并重启。官方手册没有单独写“关机步骤”，上面的顺序是根据手册的接线和安全说明整理的。

  • 会烫。手的外壳工作时和刚断电后可能很烫，断电后至少等 30 分钟再摸。
  • 会夹手。手在动的时候，手指不要靠近关节缝隙。
  • 指尖很娇贵。指尖是触觉传感器，别碰尖锐的东西，压上去的力不要超过 50 N（大约 5 公斤）。
  • 不防水。别在潮湿或有液体的地方用。
  • 出现异响、异常抖动就立刻断电。
