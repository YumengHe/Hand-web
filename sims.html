1. 谁建在谁上面

上层调用下层。三列是三条互相独立的路线：左边是停更的老一代，中间是 NVIDIA 现在的路线，右边是 DeepMind 的 MuJoCo。

  • Isaac Sim 是仿真器本体：管物理、渲染、传感器、场景。Isaac Lab 是装在它上面的一层：把仿真包装成强化学习环境（观测、动作、奖励、随机化、成千上万个环境一起跑）和训练脚本。
  • Isaac Gym 和 Isaac Sim / Lab 不是上下级，是前后两代。Isaac Gym 是独立程序，官方已标为停更，推荐改用 Isaac Lab；它的任务库 IsaacGymEnvs 和过渡版 OmniIsaacGymEnvs 都已归档。
  • Isaac Lab 3.0 起不再只能跑在 Isaac Sim 上：物理后端可选 PhysX（经 Isaac Sim）或 Newton（可以不装 Isaac Sim）。我们的移植版仍用 PhysX 后端。
  • MuJoCo 不是 NVIDIA 的，是另一棵独立的树。两边的交点是 Newton：它的主后端 MuJoCo Warp 由 DeepMind 和 NVIDIA 共同维护。

3. Isaac Sim 和 Isaac Lab：版本要配对

Isaac Lab 每个版本只对应特定的 Isaac Sim 版本，换一个就要两个一起换。

Isaac Lab1.02.02.22.33.0 beta3.0.0
Isaac Sim4.0（兼容 2023.1.1）4.55.0（兼容 4.5）5.16.06.2
谁在用官方 sharpa-rl-lab 测过这两版我们的移植版

Isaac Lab 3.0 相对 2.x 的主要变化：

  • 物理后端可以换：PhysX（默认）或 Newton；用 Newton 时可以不装 Isaac Sim。
  • 渲染器也可以换：Isaac RTX、OVRTX、Newton Warp。
  • 环境里的数据改成 Warp 数组。
  • Python 从 3.11 升到 3.12，推荐用 uv 安装。

我们移植时保留了 PhysX 后端和 2.x 的执行器写法，改动记在 任务 1。

4. MuJoCo 是什么

MuJoCo 只是一个物理引擎：一个 C 库加 Python 绑定，用一个 xml 文件（MJCF）描述机器人和物体，算关节、接触和摩擦。它不带强化学习框架，也不带照片级渲染。它最早是商业软件，2021 年 10 月被 DeepMind 收购，2022 年 5 月以 Apache-2.0 开源。

做灵巧操作研究的人常用它。原因有三条：

  • 名字里就有 “with Contact”：设计目标就是多关节、多接触的动力学。
  • 一个 xml 就能看懂整个模型，pip install mujoco 就能跑，单步调试和可视化方便。
  • 不需要特定显卡。

和 Isaac 路线的取舍（两边都在向对方靠拢，没有谁更好）：

  • MuJoCo 的强项：单个环境好调、模型好改。原生在 CPU 上跑，要上 GPU 并行得换 MJX 或 MuJoCo Warp。
  • Isaac 的强项：一开始就是 GPU 上几千个环境一起跑，还有 RTX 相机渲染和 USD 场景。代价是安装重，而且要 RTX 显卡。
  • 两边的交点：MuJoCo Warp 现在是 Newton 的主后端，Isaac Lab 3.0 又能直接用 Newton。
  • MuJoCo Playground（DeepMind 等，2025）是 MuJoCo 这边的训练框架：基于 MJX，现在也支持 MuJoCo Warp；带四足、人形、灵巧手和机械臂的环境，相机渲染用 Madrona 批量渲染器。

5. 和我们的关系

东西用的平台本机（RTX 5090）能不能训练
sharpa-rl-lab（手里转圆柱） 官方测过 Isaac Lab 2.2 / 2.3。我们移植到 Isaac Lab 3.0 + Isaac Sim 6.2，PhysX 后端，conda 环境 env_isaaclab3，16384 个并行环境 能，见 任务 1
WM-Craftnet（Sharpa 官方另一项工作） Isaac Gym Preview 4 + Python 3.8 + PyTorch 2.1 / CUDA 11.8（据其 README 的安装要求） 不能，只能拿它放出的模型做部署。原因有两层：Isaac Gym 自带的 PhysX GPU 库没有 RTX 50 系（sm_120）的代码，NVIDIA 确认不会再更新；PyTorch 要 2.7 起、用 CUDA 12.8 的版本才支持 50 系，2.1 / CUDA 11.8 不行
sharpa-urdf-usd-xml（Sharpa 官方模型文件） Sharpa Wave 左手、右手、双手各给 URDF、USD、MuJoCo xml（MJCF）三种格式，分带手腕和带法兰两种。三条路线都能直接用 不涉及训练；许可 GitHub 标为 “Other”，看仓库里的 LICENSE.txt
